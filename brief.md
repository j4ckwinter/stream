# What to Wear Today

Build something that helps a user decide what to wear today based on their location and the weather.

The exercise is split into two briefs, each intended for its own repository:

- [Frontend brief](./fe-brief.md): build the user experience in TypeScript, using a backend API or a mock.
- [Backend brief](./be-brief.md): build a TypeScript API that uses Open-Meteo to return weather-based clothing advice.

Each exercise allows 5 minutes for clarifying questions followed by 40 minutes to build. Framework and agentic tooling choices are open. Persistence (a database) and automated testing are not in scope to build; both will be discussed in the debrief.

The briefs can be completed independently. If the repositories are connected, agree on the API request, response, and error format before starting. The backend owns weather retrieval and recommendation logic; the frontend owns location input and presentation.
